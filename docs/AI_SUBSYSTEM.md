# AI Subsystem

## Philosophy

The workstation does not expose models.

The workstation exposes engineering intent.

Models, providers, and runtimes are implementation details that can change over time without changing the user's workflow.

## Roles

- Engineer
- Architect
- Analyst
- Writer
- Teacher
- Builder
- Creator
- Automate
- Bootstrap

## Context Engine

The Context Engine is responsible for gathering all relevant information before invoking an AI provider.

Responsibilities:

- Detect the current project
- Detect the current language(s)
- Detect Git repository state
- Read project documentation (README, PLAN.md, ROADMAP.md, etc.)
- Select the appropriate AI role
- Select the appropriate AI provider and model
- Build a high-quality prompt

The user should express intent.

The workstation is responsible for constructing context.
