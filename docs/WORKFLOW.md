# Engineering Workflows

The workstation is organized around engineering workflows, not AI models.

## Core Workflows

### Engineer

Intent:
Evaluate a codebase, identify issues, propose a plan, and implement changes.

Inputs:
- Current repository
- Git state
- Project documentation
- User request

Outputs:
- Analysis
- Plan
- Code changes
- Verification

---

### Architect

Intent:
Design systems, evaluate tradeoffs, and recommend implementation approaches.

---

### Analyst

Intent:
Analyze supplied information and produce structured findings.

Examples:
- SWOT
- SMART goals
- Quarterly planning
- Roadmaps

---

### Writer

Intent:
Transform rough notes into polished communication.

Examples:
- Client emails
- Status updates
- Documentation
- Proposals

---

### Bootstrap

Intent:
Generate new projects or sub-projects using workstation conventions.

---

### Automate

Intent:
Identify repetitive work and produce automation.
