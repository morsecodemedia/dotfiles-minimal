# Review v1.0

## Mission

Transform repository state into engineering observations.

## Responsibilities

- Consume the Context Engine.
- Analyze repository changes.
- Summarize engineering state.
- Recommend next actions.

## Non-Goals

- Replace Git.
- Generate code.
- Launch AI.
- Modify repositories.

## Definition of Done

- Consume ctx only.
- No duplicated repository collection.
- Human output.
- JSON output.
- ShellCheck clean.
- bash -n clean.
