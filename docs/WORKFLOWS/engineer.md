# Engineer Workflow

## Intent

Evaluate a software project, identify issues, establish a plan, and assist with implementation.

## Inputs

- Context Engine (`ctx`)
- README.md
- PLAN.md (optional)
- ROADMAP.md (optional)
- Git status
- Git diff (optional)

## Outputs

- Findings
- Risks
- Recommendations
- Implementation Plan
- Code (optional)

## Phases

1. Gather context
2. Understand repository
3. Analyze request
4. Create implementation plan
5. Execute changes
6. Verify changes
7. Summarize work
