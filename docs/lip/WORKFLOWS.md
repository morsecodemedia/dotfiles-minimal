# LIP Workflows

## Philosophy

Workflows describe how collaborators perform work.

Personas describe responsibilities.

These are intentionally separate concepts.

---

# Future Workflows

Additional workflows should compose existing collaborators whenever practical.

New workflows should not require creating new personas unless a genuinely new responsibility has been identified.
